# EEO MVP Scope Guardrail

## Purpose

This file protects the implementation from scope drift.

The cohesive EEO vision is broad, but the current product must remain narrow, verifiable, safe, and useful.

## MVP boundary

The MVP includes:

1. One flagship evidence dossier.
2. One limited corridor dashboard.
3. One evidence ledger.
4. One internal review workspace.
5. One right-of-reply and correction workflow.
6. One signed release manifest.
7. One safe corridor pilot.

## True MVP loop

source -> license -> evidence -> claim -> entity resolution -> review -> exposure review -> right-of-reply if needed -> release manifest -> public evidence dossier -> correction route

## Human Dependency Layer rule

The Human Dependency and Stewardship Layer may be described and modeled at a high level.

It should not expose sensitive population, ethnic, community, sacred-site, displacement, or household-level data.

Use aggregated, public, rights-aware indicators only.

## Safe public language

Use:

- documents available evidence;
- connects claims to sources;
- identifies uncertainty;
- supports public-interest inquiry;
- makes no legal finding;
- uses rights-aware disclosure;
- treats trade data as context;
- treats public revenue as a question, not proof of benefit.

Avoid:

- proves guilt;
- certifies stewardship;
- ranks actors;
- assigns legal responsibility;
- verifies origin from trade data alone;
- proves causation from proximity alone;
- owns or reallocates resources.
