# Right-of-Reply, Corrections, and Maintenance

## Right-of-Reply Triggers

Require right-of-reply before named high-impact publication involving:

- named company risk profile;
- named public agency risk profile;
- named beneficial owner risk profile;
- named operator linked to unresolved allegation;
- named actor connected to severe labor, ecological, corruption, or public-benefit risk;
- contested ownership/control claim with reputational consequence.

## Correction Workflow

```text
correction submitted
→ triage
→ severity assigned
→ claim frozen/labeled if needed
→ source evidence reviewed
→ additional evidence requested if needed
→ decision: correct / reaffirm / withdraw / mark disputed
→ correction note published
→ release manifest updated
```

## Severity Levels

| Level | Example | Response |
|---|---|---|
| Low | Typo, broken link | Fix and log if material |
| Medium | Outdated source, missing caveat | Update claim and correction log |
| High | Wrong named actor, ownership error | Temporarily label, correct, or withdraw |
| Critical | Exposure harm, legal risk, safety threat | Immediate suppression and governance review |

## Maintenance Cadence

| Item | Frequency |
|---|---:|
| Source registry | Monthly |
| Concession/contract records | Quarterly |
| Beneficial ownership records | Quarterly or semiannual |
| Trade data | Quarterly or annual |
| Labor indicators | Annual or latest available |
| Ecological indicators | Source-dependent |
| Public revenue data | Annual/reporting cycle |
| Methodology notes | Every release |
| Correction log | Continuous |
| Security dependencies | Monthly |

## Monthly Checklist

- review stale claims;
- review correction queue;
- verify source links;
- review high-impact claims;
- update methodology log;
- review suppressions and disclosure tiers;
- audit admin access;
- patch dependencies;
- test backups;
- test correction route;
- check accessibility and broken links.
