# ADR-001: Controlled Evidence Product First

**Status:** Accepted  
**Date:** 2026-04-26

---

## Context

Early versions of the EEO concept imagined a global, multi-resource, real-time platform: a full atlas, composite scores, AI-driven analysis, a community reporting module, a blockchain trust layer, and broad public data submission.

That scope creates an institution that claims too much, exposes too much, can be captured by any of several interests, and cannot be trusted with the sensitive evidence it would need to do its job.

The alternative is to start with a controlled, evidence-first product that proves the institutional loop before expanding outward.

## Decision

The first public product is a **flagship corridor evidence dossier** with a limited dashboard and an evidence ledger — not a platform, not an atlas, and not a scoring tool.

The first build loop is:

```
source → license → evidence → claim → entity resolution → review → exposure review → right-of-reply if needed → release manifest → public evidence dossier → correction route
```

Every future expansion must be earned by demonstrating that this loop works reliably, safely, and with institutional credibility.

## Consequences

- The first pilot is scoped to one corridor (copper-cobalt critical minerals).
- Deferred features (atlas, scores, rankings, community reporting, blockchain, AI authority) are not in scope for MVP and require explicit governance decisions before activation.
- This forces the team to solve the hard problems — licensing, provenance, exposure review, right-of-reply, release gates — before expanding.
- Funders, partners, and users see a disciplined institution, not an over-promised platform.
- The project can be wrong about specific claims and correct them without destroying institutional credibility.
