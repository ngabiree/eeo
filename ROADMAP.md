# EEO Version Roadmap

The build sequence is intentionally staged to keep public claims governed before adding any monitoring-style surfaces.

## Ordered releases

1. `v0.5` — Claim governance and release consequences
2. `v0.6` — Temporal Endowment Profile design + data model only
3. `v0.7` — Monitoring signal registry
4. `v0.8` — Scenario notes / disciplined foresight

## Guardrail for `v0.6`

`v0.6` must not introduce a monitoring dashboard, signal scoring UI, or trend-performance framing.
It is limited to schema design, field definitions, validation posture, and model documentation for Temporal Endowment Profiles.
